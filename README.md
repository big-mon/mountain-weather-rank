# mountain-weather-rank

お気に入りの山を、土日の風・降水・雲量で見比べる個人用Webアプリです。最大5山を登録でき、選択した日の天気条件がよい順に並びます。

## 公開版

[週末の山の天気](https://app.damonge.com/mountain-weather-rank/) — [App Hub](https://app.damonge.com/) からも開けます。

## 起動

Python 3で、このフォルダから起動します。インストールやビルドは不要です。

```sh
git clone https://github.com/big-mon/mountain-weather-rank.git
cd mountain-weather-rank
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで <http://127.0.0.1:8000> を開いてください。ES Modulesを使うため、HTMLファイルの直接オープンでは動きません。停止はターミナルで `Ctrl+C` です。

## 使い方

- 最初は高尾山・筑波山・丹沢山・大菩薩嶺・雲取山の5山を表示します。
- 土曜／日曜を切り替えると、その日の天気で順位が変わります。
- 各山の「編集」で山名・緯度・経度・標高を編集、または削除できます。5山未満なら「山を追加」で登録できます。
- 緯度経度は山頂の座標を10進数で入力します。標高はメートル単位です。
- お気に入りと予報は、このブラウザのlocalStorageに保存します。全山を削除してもサンプルは復元しません。保存機能が使えない場合は画面に通知します。
- 予報は30分キャッシュします。「予報を更新」または各山の「予報を再取得」で、最新データを取得できます。

対象週末と時刻は日本時間です。月〜金は直近の土日、土日はその週の土日を表示し、日曜に開いた場合は日曜を初期選択します。

## データと比較方法

[Open-Meteo Forecast API](https://open-meteo.com/en/docs) の非商用無料枠を使用します。APIキーは不要で、ブラウザから直接取得します。利用にはインターネット接続が必要です。

風・雲は1000 / 975 / 950 / 925 / 900 / 850 / 800 / 700 / 600hPaの風速・雲量・ジオポテンシャル高度を取得し、時刻ごとに山頂標高を挟む2高度から線形補間します。これは山頂高度付近の大気の推定で、局地的な尾根の増速や突風、山頂の視程を再現するものではありません。雲量はその高度の推定で、全天の雲量とは異なります。

各日6〜15時の10時点から最大風速と平均雲量を計算します。降水量は登録地点の雨・雪などの水当量です。直前1時間の累計値なので、07〜15時の9件を合計して6〜15時の降水量とします。

```text
比較値 = 0.50 × 最大風速(m/s) / 10
       + 0.35 × 合計降水量(mm) / 10
       + 0.15 × 平均雲量(%) / 100
```

小さい順に並べ、同点なら登録順を保ちます。値を上限で打ち切りません。分母は比較用の尺度で、安全の閾値ではありません。順位は天気3項目の比較で、登山可否やルート難度を評価しません。

1時間でも必要なデータが欠けた項目は「—」と表示します。必要な3項目が揃わない日、標高を挟む高度データがない山、30分以上前の予報は順位対象外です。範囲外の標高への外挿や地上風への置き換えは行いません。古い予報は取得時刻とともに残し、通信失敗時も他の山は比較できます。

予報は [Open-Meteo](https://open-meteo.com/) による [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) データを高度補間・時間集計しています。初期の山名・座標・標高は [国土地理院「日本の主な山岳」](https://maps.gsi.go.jp/3d/mountain/mountain.html) に基づき、座標を度分秒から10進数に変換しています。

## 検証

Node.js 22以降の標準テストランナーを使います。追加パッケージは不要です。

```sh
node --test
TZ=America/Los_Angeles node --test
```

日付境界・高度補間・降水の対象時間・順位と同点・欠損・キャッシュ期限・API失敗を検証します。

構成は `index.html`、`styles.css`、画面操作の `src/app.mjs`、純粋な計算の `src/core.mjs`、取得処理の `src/weather.mjs` です。ログイン・端末間同期・地図検索・通知は初版の対象外です。
